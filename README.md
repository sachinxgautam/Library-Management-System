# Library Management System

A simple Library Management System developed using C language. This project helps manage books through a menu-driven console application.

## Features

- Add new books
- View all available books
- Search books using Book ID
- Issue books
- Return books
- Check book availability
- Save book records automatically using file handling

## Technologies Used

- C Programming
- Structures
- Functions
- File Handling
- Loops and Conditional Statements

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

gcc main.c -o library.exe
5. Run the program:

./library.exe
For Windows PowerShell:

.\library.exe
